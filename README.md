# hd
A simple hex dumper, written for myself whilst working with ROMs.

Arguments:
```
-bpr int
  	Bytes per row (default 16)
-file string
  	File (default "test.txt")
-ofl int
  	Offset length (default 8)
-search string
  	Search for a pattern
```
